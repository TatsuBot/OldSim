OldSim — Local Usage Guide
==========================

Prerequisites
-------------
- Node.js 18+ (20/22 recommended)
- From the project root (folder with package.json):

    npm install


Run the test suite
------------------
    npm test

All phases (1–10) are covered by unit/integration tests.


List available NPCs
-------------------
    npx tsx src/runner/battleBuilder.ts --list


Run a Monte Carlo matchup (battle builder)
------------------------------------------
Writes public/results.json and public/replay.json

    npm run battle

    npm run battle -- --a 415:1 --b 3028:10 --runs 200 --seed 7

    npm run battle -- --a 3028:20 --b 3049:5 --runs 100 --seed 42

Flags:
  --a       Army A (default 415:1)     format: id:count[,id:count...]
  --b       Army B (default 3028:8)
  --runs    Number of simulated battles (default 100)
  --seed    Master seed for reproducibility (default 1)
  --width   Arena width in tiles (default 40)
  --height  Arena height in tiles (default 40)
  --cap     Max ticks before timeout (default 1200)
  --list    List NPCs and exit
  --help    Show help

Army examples:
  415:1              one Abyssal demon
  3028:10            ten Goblins
  3028:5,3049:2       five Goblins + two Hobgoblins


Quick single-battle replay export
---------------------------------
    npm run export-replay
    npx tsx src/runner/exportReplay.ts --seed 42

Writes public/replay.json only (no Monte Carlo stats).


Monte Carlo CLI (simpler default matchup)
-----------------------------------------
    npm run sim
    npx tsx src/runner/cli.ts --runs 50 --seed 1


View results + replay in the browser
------------------------------------
    npm run render

Then open:
  http://localhost:5173/results.html   → win rates, averages, SE
  http://localhost:5173/               → Three.js replay player

Replay controls:
  Play / Pause
  Speed 0.5× / 1× / 2× / 4×
  Scrub timeline
  Drag to orbit camera


Typical workflow
----------------
1. npm install
2. npm test                          # confirm everything works
3. npx tsx src/runner/battleBuilder.ts --list
4. npm run battle -- --a 415:1 --b 3028:10 --runs 200 --seed 7
5. npm run render
6. Open results.html, then watch the replay


Recording a video (local)
-------------------------
Option A — Browser (Chrome/Edge):
  Open the replay page, open DevTools → ⋮ → More tools → Rendering
  (or use an extension / Windows Game Bar / macOS Cmd+Shift+5)

Option B — OBS Studio (recommended):
  1. Add a Window/Browser Capture of the replay tab
  2. Crop to the canvas
  3. Record at 60 fps if possible
  4. Play the replay at 1× or 2×

Option C — ffmpeg (if you capture a raw file):
  # Example: re-encode a screen capture to a smaller mp4
  ffmpeg -i capture.mov -c:v libx264 -crf 20 -preset medium -pix_fmt yuv420p -an oldsim-replay.mp4


Project layout
--------------
  data/npcs.json          NPC stats (offline)
  src/sim/                Pure simulation core (no graphics)
  src/runner/             Monte Carlo, CLI, battle builder, export
  public/index.html       Three.js replay player
  public/results.html     Results panel
  public/replay.json      Last exported / selected replay
  public/results.json     Last Monte Carlo summary
  tests/                  Vitest suite


Design rules (do not break)
---------------------------
1. Simulation never draws; renderer never decides combat/pathing.
2. Same BattleConfig + seed → identical battle, tick for tick.
3. No Math.random() inside src/sim/ — seeded RNG only.
4. Combat uses real OSRS formulas (integer floor at the same points).
